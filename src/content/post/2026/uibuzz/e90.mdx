My [journaling app](https://www.justj.app) has become increasingly vital, used daily for tracking development and social posting, revealing small usability gaps like missing a right-click menu for deleting posts—issues only noticed through regular personal use. A lesson for us all.

## Mandala Studio Web Platform

A drawing app, [Mandala Studio](https://www.getmandalastudio.com), was created as a web-based tool to experiment with geometric drawing, particularly mandala designs, offering a reusable experience without material waste. It supports image saving, printing as stencils, and now includes complex features like fills and gradient meshes, with a live demo available and beta release approaching.

## Game Development Challenges

Game development has faced setbacks, including Unreal Engine 6 dropping blueprints and C++ support, potentially disrupting legacy work. Struggles with Unity’s installation and IDE setup highlighted how broken tools can halt progress, reinforcing the value of frequent personal use in app testing.
