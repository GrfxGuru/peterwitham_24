I have many apps for many different things and as expected many of those apps can perform many different cross-over tasks.

For example

- I can write blog posts in a code editor
- I can edit code in a text editor

But the question becomes, does that make the most sense and best use of my time when it comes to working the desired task.

I chose those two examples because they are by far the one that applies to me the most.

I’ll be working away in Zed my code editor of choice over the past couple of years and once that is done, I start working on a post and do it right there.

But, it is a perfectly good text editor that lacks the ability to tune my brain into righting and thinking about the post as I create it. I cannot explain it, that is how it works with me.

On the flip side, when I’m in a text editor (I use a few) my brain locks into content creation mode and not seeing that code file off to the left that I know I need to do work on.

I go into focus mode and see a blank screen with the text I am working on, that is all.

The other advantage to using a dedicated text editor is it helps with my grammar more than a code editor. Which, is a big plus for me and the readers.

As I have said before, spend a while finding the right tools and embrace them. But, try hard to settle and not use more than one for each task.
