Thank you to the users that request new features to add to my Job Finder Tracker application. If you are not aware, on the help screen there is a feature request form that I always pay attention to.

In this new update, there are two features requested by users. Both are a great time saver I think.

### Record and sort by application date.
You now have the ability to track the job application date. This was a great suggestion and something I had not considered. There is also the option to sort the job list by the application date.

### Notifications
There has always been the ability to set a reminder in your calendar, now there is a second option to set a notification reminder. For this to work you need to allow the application access to notifications on your device(s).

These are two great quality of life updates that continue to give you a great flexible way to manage job tracking and applications. I always welcome feedback and suggestions, you can do that in the app via the feature request on the help screen or by contacting me directly using the [contact form](https://peterwitham.com/contact).
